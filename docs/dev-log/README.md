## 작성 원칙

1. **Append-only** — 이미 쓴 줄은 수정 금지. 새 정보는 아래에 추가.
2. **메트릭은 측정 가능한 수치만** — 추정·체감 표현 금지.
3. **트러블슈팅은 5W1H** — 무엇이 / 언제 / 왜 / 어떻게 / 결과·교훈.
4. **포트폴리오 친화적** — 면접관이 그대로 인용할 수 있는 1~2문장 요약을 각 항목 끝에 추가.
